# Abyss Notifications

Односторонняя отправка Markdown-задач из Obsidian / Abyss Tasks в **Apple «Напоминания» и «Календарь» через CalDAV (fruux)**. Работает в Obsidian на iOS, Android и компьютере. На iPhone для обмена должен быть открыт Obsidian.

## Установка через BRAT

1. В нужном хранилище открой **Настройки → Сторонние плагины** и установи **BRAT**.
2. В настройках BRAT нажми **Add a beta plugin**.
3. Вставь `https://github.com/iissaakkll05/abyss-notifications`, выбери последнюю версию и установи.
4. Включи **Abyss Notifications** и введи данные устройства CalDAV в его настройках.

Релиз содержит три отдельных файла: `main.js`, `manifest.json`, `styles.css`. Их также можно вручную положить в `.obsidian/plugins/abyss-notifications/`.

При установке в **другое независимое хранилище** не копируй `data.json` из прежнего: новая установка создаёт собственный идентификатор связи и собственные коллекции. Между устройствами **одного** хранилища настройки можно синхронизировать.

## Что отправляется

| В Obsidian | На сервере и телефоне |
| --- | --- |
| Задача с тегом и датой, без времени | Напоминание с датой **без уведомления** |
| Дата и одно время | Напоминание с уведомлением |
| Дата, время и явная длительность / интервал | Событие с уведомлением, без дублирующего напоминания |
| Нет даты или обычный непомеченный чекбокс | Не отправляется |

```markdown
- [ ] #task/inbox Купить продукты 📅 2026-12-01
- [ ] #category/work Позвонить ⏰ 13:00 📅 2026-12-01
- [ ] #category/work Встреча ⏰ 13:00 ⏱️ 2h 📅 2026-12-01
- [ ] #category/work Подготовка ⏰ 16:10 ⏱️ 3h50m 🛫 2026-12-01 📅 2026-12-03
    - [ ] Подзадача 📅 2026-12-02
```

Последний пример создаёт одну ограниченную серию событий: **1, 2 и 3 декабря, каждый день 16:10–20:00**. Датированная подзадача синхронизируется отдельно и наследует признак задачи от помеченного родителя; дописывать ей тег не нужно.

Распознаются `⏰ 13:00`, `⏰ 13:00–15:00`, длительности `60m`, `2h`, `1h30m`, `02:00`, поля `[time:: 13:00]`, `[duration:: 2h]` и даты 📅 / ⏳ / 🛫 (также `[due:: ...]`, `[scheduled:: ...]`, `[start:: ...]`). Приоритет срока: due → scheduled → start. Диапазон ежедневных календарных блоков определяется отдельными start и due.

Не читаются YAML, блоки кода, скрытые папки, `.sync-conflict-` копии и настроенные исключения. `#task/default` исключает задачу. Комментарии после подзадач попадают в описание родителя, собственные комментарии подзадач остаются у подзадач. Служебные метки времени комментариев Abyss и обёртка описания `- >` в описание на телефоне не попадают. Путь к заметке и ссылка Obsidian не добавляются.

## Подключение fruux и Apple

В аккаунте [fruux](https://fruux.com/) создай данные устройства для синхронизации. В плагине укажи сервер `https://dav.fruux.com/`, выданный логин и пароль устройства. Проверка подключения только читает сервер.

На iPhone добавь CalDAV-аккаунт fruux в настройках «Напоминаний» / «Календаря» и включи обе службы. Если аккаунт уже подключён, второе подключение не требуется. Устройства fruux одного аккаунта видят его общие данные.

При первом обмене плагин создаст две коллекции:

- `<Название хранилища> — Напоминания`;
- `<Название хранилища> — Календарь`.

Проекты и источники не создают дополнительных списков. Переименование хранилища переименовывает прежние коллекции. Разреши уведомления приложениям телефона. Android требует совместимого клиента / синхронизатора CalDAV; работа системных уведомлений зависит от выбранного приложения.

## Один источник изменений

**Редактируй, выполняй и удаляй задачи в Obsidian.** Изменения отправляются на сервер. Выполнение напоминания на телефоне будет отменено следующим обменом, если в Obsidian задача осталась открытой. Изменённое или удалённое управляемое событие также восстанавливается по заметке.

Новые задачи, созданные прямо на телефоне, **не импортируются**. Плагин восстанавливает прежнюю запись при случайном выполнении и подхватывает её новый адрес, если Apple сохранил UID. Выполненные копии с новым UID удаляются после восстановления исходной задачи только при совпадении названия, описания и даты/времени с единственной задачей Obsidian. Неоднозначные копии, записи другого хранилища и остальные ручные задачи сохраняются. Обратной синхронизации нет.

- Удаление локальной задачи, её даты или признака задачи удаляет управляемую запись. Потеря собственного тега у подзадачи не исключает её, пока она находится под помеченным родителем.
- Удаление времени оставляет напоминание с датой без уведомления.
- Добавление / удаление длительности переносит запись между напоминаниями и событиями. При обрыве сети между удалением старой и созданием новой возможен временный промежуток без серверной записи; следующий обмен его восстановит.
- Выполненное напоминание отмечается выполненным, событие получает ✅. Сигналы отключаются. Выполненные задачи с тегом и датой отправляются и при первой синхронизации.
- В Напоминания отправляется только текущий экземпляр повторяющейся задачи, без серверного RRULE. Следующий экземпляр создаёт Obsidian / Tasks / Abyss; затем нужен обмен при открытом Obsidian. Это предотвращает создание второй цепочки задач самим приложением телефона. В календаре поддержаны дни, недели, месяцы, годы, интервалы, рабочие дни, указанные дни недели, `until YYYY-MM-DD`; обычный повтор прекращается при выполнении. У завершённого диапазона start–due остаются дневные блоки с ✅, без сигналов.
- `when done` отправляется как текущий экземпляр; следующую дату после выполнения рассчитывает Obsidian. Остальные сложные повторы и сочетание отдельного повтора с диапазоном start–due пока пропускаются, сохраняя прежнюю серверную запись. Причина видна в «Состоянии».

## Синхронизация и нагрузка

По умолчанию автоматика работает **только на телефоне**. Можно выбрать компьютер или оба устройства. Команда **Abyss Notifications: Синхронизировать сейчас** работает на любом устройстве независимо от автоматики.

После ввода выдерживается 5 секунд (настраивается). Сервер проверяется раз в 5 минут; можно выбрать 1 или 15 минут. Заметки кэшируются: повторный пустой обмен не читает их тексты и не переписывает заметки, настройки или задачи. Для проверки сервера используются версии записей. Изменённые и неизвестные записи собственных списков читаются условным GET, без импорта в заметки; содержимое кэшируется по адресу и версии в памяти (до 256 записей).

При закрытом Obsidian плагин на iOS не выполняет фоновую работу. Если автоматика только на телефоне, правки с ПК отправятся после передачи заметки и открытия Obsidian на телефоне. Одновременное редактирование файлов на разных устройствах по-прежнему может вызвать конфликты файловой синхронизации.

## Данные и диагностика

При первой отправке датированная задача, включая выполненную, получает скрытый комментарий `<!-- dav:... -->` со стабильным ID. Метка скрывается в редакторе и календаре Abyss средствами плагина. Исходные тексты комментариев не переписываются. При обычном копировании задачи удали скопированную ID-метку, чтобы копия получила собственную. Скопированные метки при создании следующего экземпляра повторяющейся задачи исправляются автоматически для однозначной цепочки дат: прежнее напоминание завершается, следующая дата получает собственную связь. Неоднозначные копии остаются пропусками.

**Пароль CalDAV хранится в `data.json` внутри хранилища.** Учитывай это при синхронизации и передаче файлов. Не публикуй этот файл. Плагин обращается к настроенному CalDAV-серверу; отдельного сервиса авторизации и Google Apps Script нет. На первой установке может перенести подключение из локальных настроек прежнего `task-calendar-bridge`, если они существуют; старое состояние обмена не импортируется. Одновременный экспорт с включённым старым плагином блокируется.

После ошибки плагин ждёт 5, 10, 20, затем 30 минут между автоматическими попытками. Ручной запуск доступен в паузе. Успешный ручной обмен, отправка изменений и восстановление связи показывают уведомление. Ошибки и время следующей попытки видны в состоянии и журнале. Открытый журнал обновляется во время обмена, новые записи появляются сверху. Есть команды **Состояние и пропущенные задачи** и **Открыть журнал**. Журнал не содержит пароли, авторизацию, тексты задач, геолокацию или тела сетевых запросов.

Старые коллекции другого плагина автоматически не удаляются. Перед удалением сохрани записи, которых нет в Obsidian, и отключи старый плагин на всех устройствах. Старое `⏱️ 60m` считается явной длительностью: убери его у задачи, которая должна быть обычным напоминанием.

## Разработка и выпуск

Для сборки и основных проверок достаточно Node.js 22+, без установки зависимостей:

```sh
node build.cjs
node tests.cjs
node plugin.test.cjs
node identity.test.cjs
node projection.test.cjs
node mirror.test.cjs
node mobile-network.test.cjs
node verify-release.cjs
```

`browser.test.cjs` дополнительно проверяет XML CalDAV, запросы iOS и вёрстку на 390/1200 px в изолированном Edge на Windows. Тесты используют вымышленный сервер и не обращаются к пользовательским аккаунтам.

GitHub Actions проверяет изменения main и публикует новую версию из `manifest.json`, если такой релиз ещё не существует. Файлы релиза: `main.js`, `manifest.json`, `styles.css`. Для следующей версии обнови manifest и версию, показываемую в настройках, собери `main.js` и отправь изменения в main. Уже опубликованные версии автоматически не перезаписываются. Создавать личный GitHub-токен для этого не нужно.

Плагин не аффилирован с Obsidian, Abyss Tasks, Apple или fruux. Совместимость и реальная доставка уведомлений зависят от версии клиента и CalDAV-провайдера; протестируй свою связку после установки.

Исправлены повторные отправки при различном регистре/отсутствии ETag в ответе iOS. При изменении версии собственного ресурса выполняется точечная проверка содержимого: служебные поля не вызывают лишнюю запись, а реальные правки восстанавливаются по Obsidian. GET не импортирует данные в заметки. Итоговый счётчик считает уникальные изменённые задачи; операции PUT/DELETE отображаются отдельно.

Исправлено восстановление случайно выполненного напоминания и связь после перемещения записи Apple. Однозначно распознанные выполненные копии очищаются после восстановления оригинала. Выгружаются изначально выполненные задачи. Повтор напоминаний полностью рассчитывается в Obsidian/Abyss; нативный RRULE остаётся только у событий. Добавлены 11 сценариев проверки восстановления, копий, сети и повторного пустого обмена.

Версия 1.0.10 распознаёт длительность перед приоритетом Abyss. При выполнении регулярной задачи плагин восстанавливает отдельные метки для однозначной цепочки дат. Состояние считает каждую пропущенную строку один раз.
